# Irth OS (إرث).
Irth is an Open-Source OS, written in Rust, 
with the point of only supporting Arabic, as a way to make an "Enviornment" that is Arabic only, yet Capable (At least. For Devs..)

# Goals:
As you might already guessed, this Project might not go so far.
But yet I got some stuff in mind:
  1: Real usable systems, for example user written program that is written with an Arabic Programming Language. with names not being "Forced"/"Translated", but uses Arabic's big potential (That almost no one sees, or are interested on.)
  2: to be usable(Hopefully), at least, it can be usable for one of those old laptops everyone got.
  3: The biggest one, is for me to learn.. yeah, why would anyone ever make a Hobby OS? (Unless I ever took this Project Seriously..)

# Just. Why?
  You might say why not just make any of those goals with a Real Operating System?
  But my points are more of it being a "Why Not?" or "What if?".
  And wouldn't it be interesting for an Enviorment that is made to be: RTL(Right-to-Left) Compatible And Focused on Arabic Not Forced. 
  (+ The idea of building everything from zero is much more interesting to me.)
 
If you want to Support a Simple Star is Enough.
